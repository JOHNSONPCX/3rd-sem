


## **Advantages of Synchronization**

1. Prevents race conditions.
    
2. Maintains data consistency.
    
3. Provides thread safety.
    
4. Controls access to shared resources.
    
5. Prevents multiple threads from simultaneously executing the same protected section under the same lock.

## **Disadvantages of Synchronization**

1. Can reduce program performance.
    
2. Threads may have to wait.
    
3. Can cause deadlock.
    
4. Excessive synchronization reduces concurrency.
